# paper-review：公共管理论文辅导技能（v0.3.0）

面向**公共管理在职研究生（MPA）**的论文辅导 Skill。装进 Claude 之后，它会以博士生导师的视角和你对话：用大白话讲，多举公共管理里的实际例子，指出问题的同时给出修改方向，结尾给你鼓励。

## 两种工作方式

不需要手动选择，Claude 会根据你发的内容自动判断。

| 你发的内容 | 进入的模式 |
|---|---|
| 论文、大纲或某几章，或明确说"帮我审阅""点评""给修改意见" | **评阅模式** |
| 只有一个想法、一个现象，不知道该研究什么 | **拷问模式（Grill-me）** |

### 评阅模式

先判断论文类型，再按对应规则逐项审阅：

| 类型 | 识别特征 | 重点检查 |
|---|---|---|
| 第一类：问题-原因-对策 | 章节为"现状—原因—对策"，无假设检验 | 原因分析是否真正来自理论；对策是否与原因逐一对应 |
| 第二类：实证研究 | 有回归、结构方程、量表、统计建模 | 方法使用是否正确；信效度是否误用；各方法专项检查 |
| 第三类：案例研究 | 围绕特定地区、机构或事件，质性或 QCA | 是"理论对话"还是"用理论套案例"；案例选择、证据、QCA 校准与阈值 |
| 第四类：纯调查描述 | 问卷或访谈，仅描述统计 | 有无不必要的信效度分析；结论是否过度推论 |

输出一份结构化审阅报告：每个维度标注"通过"或"存在问题"并给出具体说明，再给综合评级（优秀 / 需小修 / 需大修 / 不合格），最后按优先级列出 3–5 条核心修改建议。

第二类覆盖的专项检查包括：OLS 回归、中介效应、调节效应、结构方程模型、逻辑回归、双重差分、多层线性模型、面板数据、断点回归、倾向得分匹配、DEA、实验法。

### 拷问模式（Grill-me）

把模糊的"现象"提炼成可研究的"问题"。三条铁律：

1. 一次只问一个问题；
2. 每个问题附带 2–3 个选项（A/B/C）；
3. 你明确回复"是"确认核心研究问题之前，不会给大纲和方案。

流程为：事实剥离 → 提炼成"为什么"问题并请你确认 → 确认后生成研究大纲（至三级目录）、文献检索方向、资料收集建议和理论建议。

## 安装（Claude）

1. 下载 `paper-review` 压缩包（见本仓库 Releases；或把本仓库中的 `paper-review` 文件夹自行压缩为 zip，**文件夹名必须是 `paper-review`**）。
2. 在 Claude 的 **Settings → Capabilities** 中打开 **Code execution and file creation**。
3. 进入 **Customize → Skills**，点击 **+ → Create skill → Upload a skill**，上传 zip（无需解压）。
4. 在技能列表中确认 `paper-review` 处于开启状态。

之后新开对话即可使用，例如：

- 上传论文后说："帮我审阅这篇论文"
- 或者说："我想研究基层治理方向，但不知道怎么定题"

没有触发时，可明确说一句"请使用 paper-review 技能"。界面名称可能随 Claude 版本调整，以实际界面为准。

## 目录结构

```
paper-review/
├── SKILL.md                              # 主文件：角色设定、模式判断、工作流程
└── references/
    ├── type1-problem-cause-solution.md   # 第一类审阅规则与输出模板
    ├── type2-empirical-research.md       # 第二类审阅规则、专项检查与输出模板
    ├── type3-case-study.md               # 第三类审阅规则（含单案例/多案例/QCA）

```

## 使用提醒

- 它是辅导工具，不是代笔工具，论文需要你自己完成。
- 它的意见仅供参考，最终以指导教师的意见为准。
- 上传前请对单位内部数据、受访者个人信息做匿名化处理。
